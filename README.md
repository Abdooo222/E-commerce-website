# E-Commerce Website

A simple static e-commerce website built with **HTML**, **CSS**, and **JavaScript**, deployed using **GitHub Pages**.

🔗 **Live Demo:**  
https://abdooo222.github.io/E-commerce-website/

---

## 📌 Overview
This project is a basic but clean e-commerce frontend that displays products, allows users to add items to a cart, and navigate between pages.  
It is ideal for beginners learning web development or building a basic online store UI.

---

## ✨ Features
- 🛒 **Product Listing Page**
- ➕ **Add to Cart Functionality**
- 📦 **Cart Page with Item Display**
- 📱 **Responsive Layout**
- 🖼️ **Product images included**
- 🔄 Easily extendable with more pages & features
